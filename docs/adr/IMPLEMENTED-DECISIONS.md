# Implemented Decisions Summary

**Purpose:** Record implemented Vityo decisions that are still true in the current codebase; this file is a compressed current-state index, not a plan queue and not a historical archive.

**Last updated:** 2026-06-29

## Reading Contract

1. A row may describe only behavior that has a current implementation anchor,
   current verification anchor, or active owning SSOT in this repository.
2. Active rules live in the owning design, spec, runbook, gate, or code surface.
   This file points to those owners instead of replacing them.
3. Standalone ADRs are for decisions that still need direct architectural
   review or have not yet been absorbed into a stable owner. Once implemented
   and absorbed, summarize the durable decision here or in the owning SSOT.
4. If an implementation anchor is removed, renamed, or reworked, update this
   file in the same change. Do not preserve old wording here for continuity.
5. Adjacent gaps stay explicit in the "Not claimed" column. A partially
   implemented area must not be promoted to a fully implemented decision.

- Update this file when implemented decisions move, merge, or stop matching the
  current code. Prefer deleting stale rows over adding historical qualifiers.

  back into this file or the owner SSOT.
